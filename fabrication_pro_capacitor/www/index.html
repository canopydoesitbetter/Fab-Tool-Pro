Fabrication Rules Used

Raw sheet: 120" long. Maximum usable cut length: 119½".
Long side: adds a 1" corner flange at each outer end.
Short side: no corner flanges. It attaches to the long-side corner flanges.
Split pieces: finished coverage is divided equally. Each seam edge receives a 1" seam flange.
The 119½" limit is applied to the actual cut blank, including flange material. Therefore a one-piece long side can cover up to 117½" finished length.

Automatic Product & Material Rules

.063 Exterior Panel: add 1" flange on every side, so 2" is added to both finished height and width. Uses .063 Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
.063 Exterior Door Panel: add ¾" flange on every side, so 1½" is added to both finished height and width. Uses .063 Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
Interior ACP Panel: subtract ⅛" from finished height and width. Uses ACP Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
Insulation Panel: subtract ½" from finished height and width. Uses Cellulose, 120" × 48" usable sheet.
Plywood Reinforcement: subtract ¾" from finished height and width. Uses Plywood, 95⅞" × 47⅞" usable sheet.
Shear rule: .063 Aluminum and ACP layouts are guillotine/shear-compatible. Every separating cut is validated internally as a full-edge cut across the current rectangular section—no stopped cuts into the middle of material are allowed. Whole-job optimization still ignores entry order when assigning parts to sheets. Cellulose and plywood keep free-form nesting with dotted internal cut paths. Grain Flow Rotation: OFF allows free 90° nesting. ON locks each part to its entered Width × Height orientation, with Width along the sheet's long/grain axis and Height along the short axis. No kerf or gap is added because none was specified.

Saw Optimization Rule

Kerf: a fixed 1/4" is consumed between adjacent finished pieces cut from the same stock tube.
Optimization: entry order does not control cutting order. The full part list is regrouped to minimize stock tube count and then reduce leftover material.
Cut tracking: each physical piece can be marked Cut or Uncut from the optimized tube list. The Part List drawer summarizes cut progress for each entered row.
Job files: export creates a portable JSON backup containing tube length, parts, quantities, labels, and individual cut-status marks. Import validates and loads that data, then waits for you to press Optimize Job.
The tube diagrams show exact part-length proportions, kerf locations, stock-position references, and remaining offcut. Kerf is only charged between adjacent pieces; there is no extra kerf automatically charged at the beginning or end of a stock tube.

Timer Behavior

One active task: starting a different task automatically stops the currently running task at the same timestamp, preventing overlapping labor time.
Screen lock / page change: the running timer is stored as an absolute start timestamp. The visible counter may pause while a browser is suspended, but elapsed time is recalculated correctly when the app becomes active again.
Phone/browser restart: running state is saved immediately when Start is pressed. Reopening this HTML resumes the elapsed-time calculation from the stored timestamp.
Portable backups: job and preset libraries use separate versioned JSON formats. If a job backup contains a running timer, importing it safely stops that timer at the backup's export timestamp so transfer time is not counted as labor.
Timer accuracy depends on the device clock. Manually changing the phone's date or time while a task is running can affect the measured elapsed time.
