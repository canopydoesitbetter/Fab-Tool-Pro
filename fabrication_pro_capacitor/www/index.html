Automatic Product & Material Rules

.063 Exterior Panel: add 1" flange on every side, so 2" is added to both finished height and width. Uses .063 Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
.063 Exterior Door Panel: add ¾" flange on every side, so 1½" is added to both finished height and width. Uses .063 Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
Interior ACP Panel: subtract ⅛" from finished height and width. Uses ACP Aluminum, 120" × 48" sheet, max cut 119½" × 47½".
Insulation Panel: subtract ½" from finished height and width. Uses Cellulose, 120" × 48" usable sheet.
Plywood Reinforcement: subtract ¾" from finished height and width. Uses Plywood, 95⅞" × 47⅞" usable sheet.
Shear rule: .063 Aluminum and ACP layouts are guillotine/shear-compatible. Every separating cut is validated internally as a full-edge cut across the current rectangular section—no stopped cuts into the middle of material are allowed. Whole-job optimization still ignores entry order when assigning parts to sheets. Cellulose and plywood keep free-form nesting with dotted internal cut paths. Grain Flow Rotation: OFF allows free 90° nesting. ON locks each part to its entered Width × Height orientation, with Width along the sheet's long/grain axis and Height along the short axis. No kerf or gap is added because none was specified.

Timer Behavior

One active task: starting a different task automatically stops the currently running task at the same timestamp, preventing overlapping labor time.
Screen lock / page change: the running timer is stored as an absolute start timestamp. The visible counter may pause while a browser is suspended, but elapsed time is recalculated correctly when the app becomes active again.
Phone/browser restart: running state is saved immediately when Start is pressed. Reopening this HTML resumes the elapsed-time calculation from the stored timestamp.
Portable backups: job and preset libraries use separate versioned JSON formats. If a job backup contains a running timer, importing it safely stops that timer at the backup's export timestamp so transfer time is not counted as labor.
Timer accuracy depends on the device clock. Manually changing the phone's date or time while a task is running can affect the measured elapsed time.

Calculator Guide

Function definitions

  • ÷ / × / + / − select division, multiplication, addition, or subtraction.
  • = completes the current operation. Pressing = again repeats the last operation and operand.
  • +/− toggles the displayed number between positive and negative.
  • mc / mr clear memory or recall the current memory value.
  • m− / m+ subtract the displayed value from memory or add it to memory.
  • CE / AC uses one context-sensitive key: CE clears only the entry being typed; AC clears the active calculation. Neither clears memory.
  • √x takes the square root of a non-negative displayed number.
  • % applies percentage behavior based on the pending operator.
  • π enters pi. xʸ raises the first entered value to the next entered power.
  • R2 / R0 round the displayed result to 2 decimal places or 0 decimal places.
  • Backspace / Delete delete one typed character from the right. Escape clears the active calculation when no drawer is open.
  • Copy by selecting the result text in the display and using your device or browser copy command.

Addition and subtraction

  • Enter a number, tap + or −, enter the next number, then tap =. Use +/− before or after entering a number when you need a negative operand.
  • You can continue chaining additions and subtractions; the calculator evaluates each entered operation in sequence.

Multiplication and division

  • Enter a number, tap × or ÷, enter the next number, then tap =. Chained multiplication and division are evaluated as entered.
  • Division by zero is rejected and the display shows an error instead of Infinity.

Repeating operations

  • After completing an operation, tap = again to repeat the last operator and last operand.
  • If you select an operator and press = without typing a second operand, the first operand is reused. This supports patterns such as repeated addition, multiplication, and powers.

Memory functions

  • Memory starts at 0. Tap m+ to add the displayed number or m− to subtract it.
  • Tap mr to bring the memory value to the display. Tap mc to reset memory to 0 without changing the current display.
  • AC clears the active calculation but intentionally leaves memory unchanged.

Roots, exponents and powers

  • For a square root, enter a non-negative number and tap √x.
  • For x raised to y, enter x, tap xʸ, enter y, then tap =. Negative exponents are supported with +/−.
  • Higher roots can be calculated as powers using a fractional exponent, such as raising a value to 1 ÷ n.

Order of operations

  • This handheld-style calculator evaluates operations in the order you enter them. It does not store a full algebraic expression and then apply PEMDAS automatically.
  • For grouped or priority work, calculate the parenthesized/high-priority portion first, then use that result in the remaining calculation.

Additional operations

  • Reciprocal: enter x, tap ÷, then tap = twice to obtain 1/x using the repeated-operation behavior.
  • Circle area: calculate radius squared and multiply by π. Sphere volume: calculate radius cubed, multiply by 4, divide by 3, then multiply by π.
  • Present-value and future-value style calculations can be built from powers, multiplication, division, percentages, and R2 rounding.

Percentage operations

  • With + or − pending, entering a percent converts it into that percentage of the first value. Example: 12 + 10 % displays 1.2 before = gives 13.2.
  • With × or ÷ pending, % converts the typed percent to its decimal fraction. Example: 15 × 10 % uses 0.1, while 15 ÷ 10 % divides by 0.1.
  • For tax or markup, enter the base amount + percent %, then =. For discount, use base amount − percent %, then =. Use R2 for currency-style rounding.

Correcting mistakes

  • While typing an entry, the clear key shows CE. Tap it to discard only that entry while keeping the pending operator and prior value.
  • When no entry is being typed, the same key shows AC. Tap it to reset the active calculation. Memory is preserved.
  • Backspace removes one character from the current typed entry. If you tap the wrong operator before entering the next number, tap the correct operator to replace it.
